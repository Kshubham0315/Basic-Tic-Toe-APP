🕹️ Tic Tac Toe App (Android - Java)
A simple and fun Tic Tac Toe (X-O) game built using Java in Android Studio. Play against a friend in this 2-player local mode app with a clean and intuitive UI.

📱 Features
Two-player (local) game

Responsive and user-friendly interface

Displays game result: Win / Draw

Game reset functionality

Prevents overwriting moves

🛠️ Built With
Language: Java

IDE: Android Studio

Framework: Android SDK

UI: ConstraintLayout, Buttons, TextView

🧠 Game Logic
The game board is a 3x3 grid.

Players take turns marking a cell.

A player wins by placing 3 of their marks in a row (horizontally, vertically, or diagonally).

If all cells are filled and no one wins, it's a draw.
